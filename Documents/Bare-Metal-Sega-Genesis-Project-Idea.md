# Bare Metal Sega Genesis Project Idea
Bare Metal Sega Genesis is a Sega Genesis emulator on a Raspberry Pi that does not utilize a Linux or Windows operating systems and executes directly on the hardware.  This project is similar to Bare Metal Commodore where the VICE emulator is used without any O/S distribution. (https://github.com/randyrossi/bmc64)

## Main Function
I want to create a Sega Genesis emulator that I can play on a Raspberry Pi that has excellent performance.  To do this I would it to do the following:
- Utilize the Genesis-Plus-GX-Wide emulator that leverages libretto for the emulation of the Sega Genesis.  The github for that project is at the following URL: https://github.com/libretro/Genesis-Plus-GX-Wide
- The Bare Metal Commodore project uses the Circle environment for bare metal interface to the Raspberry Pi.  The Circle programming environment should be used for the Bare Metal Sega Genesis project as well.  The Circle programming environment can be found at the following URL: https://github.com/rsta2/circle.
